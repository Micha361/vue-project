**TrainBrain**

Dieses Projekt ist ein Projekt das im IPT Untericht, mit dem Framework VUE gemacht wurde.
Es handelt sich um eine Plattform bei der Unternehmen oder Trainingsklubs ihre Schühler registrieren und verwalten können. Die Applikation wurde mit dem Framework VUE erstellt und die Daten werden mit Airtable gespeichert.
